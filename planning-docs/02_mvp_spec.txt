=========================================
02. MVP SPEC
100 Days Home
=========================================

[MVP 목표]
1~2주 안에 완성 가능한 웹앱으로 구현한다.
핵심은 "기록"이 아니라 "회복 레벨과 적응 코치 경험"이다.

[MVP 포함 기능]

1. 반려견 프로필 등록
- 이름
- 입양일
- 생일 또는 추정 나이
- 견종
- 성격 태그
- 프로필 이미지 URL 또는 기본 이미지

2. 하루 체크인
입력 항목:
- 오늘 감정 상태
  - 안정
  - 긴장
  - 불안
  - 활발
  - 무기력

- 행동 태그
  - 밥 잘 먹음
  - 산책 성공
  - 꼬리 흔듦
  - 이름 반응
  - 스킨십 허용
  - 보호자 따라다님
  - 숨는 행동
  - 낯선 사람 경계
  - 짖음 감소
  - 편안한 수면

- 한 줄 메모
- 체크인 날짜

3. 회복 레벨 시스템
체크인 행동 태그를 기반으로 점수를 계산한다.

긍정 행동 점수:
- 밥 잘 먹음: +5
- 산책 성공: +8
- 꼬리 흔듦: +10
- 이름 반응: +10
- 스킨십 허용: +12
- 보호자 따라다님: +8
- 짖음 감소: +6
- 편안한 수면: +10

주의 행동 점수:
- 숨는 행동: -6
- 낯선 사람 경계: -5
- 불안 상태: -4
- 무기력 상태: -3

레벨 기준:
- Lv1 적응 준비: 0 ~ 24
- Lv2 환경 탐색: 25 ~ 49
- Lv3 신뢰 형성: 50 ~ 74
- Lv4 안정화: 75 ~ 99
- Lv5 가족 완성: 100 이상

점수 계산 방식:
- 전체 체크인 점수 합산
- 단, 음수 점수는 전체 점수를 0 아래로 내리지 않음
- MVP에서는 단순 누적 점수 사용
- 추후 최근 7일 가중치 방식으로 개선 가능

4. 오늘의 적응 코치
AI 없이 Rule 기반으로 제공한다.

예시 규칙:
- 감정이 불안이고 숨는 행동이 있으면:
  "아직 환경이 낯설 수 있어요. 억지로 다가가기보다 안전한 공간을 유지해주세요."

- 밥 잘 먹음 + 편안한 수면이 있으면:
  "생활 리듬이 안정되고 있어요. 지금처럼 일정한 루틴을 유지해주세요."

- 이름 반응 + 보호자 따라다님이 있으면:
  "보호자와의 신뢰가 생기고 있어요. 짧은 칭찬과 간식 보상으로 좋은 경험을 쌓아주세요."

- 산책 성공이 있으면:
  "외부 환경에 대한 적응이 조금씩 진행되고 있어요. 무리하지 말고 짧은 성공 경험을 반복해주세요."

5. 적응 타임라인
체크인 기록을 날짜순으로 보여준다.

표시 항목:
- Day N
- 감정 상태
- 행동 태그
- 한 줄 메모
- 특별한 업적 여부

6. 첫 순간 업적 시스템
특정 행동 태그가 처음 기록되면 업적을 unlock한다.

업적 목록:
- 첫 꼬리 흔들기: 꼬리 흔듦 첫 기록
- 첫 이름 반응: 이름 반응 첫 기록
- 첫 산책 성공: 산책 성공 첫 기록
- 첫 스킨십: 스킨십 허용 첫 기록
- 첫 편안한 수면: 편안한 수면 첫 기록
- 첫 신뢰 신호: 보호자 따라다님 첫 기록

7. 홈 화면
표시 항목:
- 강아지 이름
- 입양 후 Day N
- 현재 회복 레벨
- 회복 진행률
- 오늘 체크인 버튼
- 오늘의 적응 코치
- 최근 타임라인 3개
- unlocked 업적 일부

[MVP 제외 기능]
- 로그인
- 서버 DB
- 실제 AI API
- 사진 업로드
- 다중 반려견 관리
- 알림
- 캘린더 연동
- 병원/건강 기록
- 커뮤니티

[추후 확장 기능]
- Supabase 연동
- 사진 아카이브
- AI 적응 코치
- 주간 리포트
- 보호자 감정 기록
- 입양 100일 회고 카드 생성
