=========================================
04. VIBECODING START PROMPT
100 Days Home
=========================================

아래 프롬프트를 Cursor, ChatGPT, Claude 등에 넣고 구현을 시작한다.

-----------------------------------------

너는 React + TypeScript + Tailwind CSS 기반 웹앱을 구현하는 프론트엔드 개발 도우미야.

프로젝트명은 "100 Days Home"이야.

이 앱은 유기견 입양 후 100일 동안의 적응 과정을 돕는 웹앱이야.
단순 기록 앱이 아니라 "입양 후 적응 도우미 + 회복 레벨" 앱으로 만들어야 해.

핵심 컨셉:
- 보호자가 매일 강아지 상태를 간단히 체크인한다.
- 앱은 행동 태그를 기반으로 회복 점수와 레벨을 계산한다.
- 현재 적응 단계, 오늘의 코칭 메시지, 100일 진행률, 타임라인, 첫 순간 업적을 보여준다.

기술 스택:
- React
- Vite
- TypeScript
- Tailwind CSS
- Zustand
- React Router
- Recharts
- LocalStorage

MVP 기능:
1. 반려견 프로필 등록
2. 하루 체크인
3. 회복 레벨 계산
4. Rule 기반 적응 코치 메시지
5. 타임라인
6. 첫 순간 업적
7. 홈 대시보드

페이지:
- HomePage
- CheckInPage
- TimelinePage
- AchievementPage
- MyDogPage

디자인 방향:
- 따뜻하고 부드러운 반려동물 앱 느낌
- 베이지/크림톤 기반
- 카드형 UI
- 모바일 우선 반응형
- 버튼은 큼직하고 명확하게
- 문장은 보호자를 안심시키는 톤

중요:
- MVP에서는 서버 DB와 로그인은 사용하지 않는다.
- 모든 데이터는 Zustand + LocalStorage로 관리한다.
- AI API는 쓰지 않고 Rule 기반 코칭 메시지만 구현한다.
- 코드에는 초보자가 이해할 수 있도록 핵심 함수에 주석을 달아준다.
- 한 번에 너무 많은 기능을 만들지 말고, 단계별로 구현한다.

먼저 아래 작업부터 진행해줘.

1. 프로젝트 폴더 구조 제안
2. 필요한 타입 정의
3. constants 파일 설계
4. Zustand store 설계
5. 라우팅 구조
6. 기본 레이아웃 구현

그 다음 내가 "다음"이라고 하면 페이지별 구현으로 넘어가줘.
