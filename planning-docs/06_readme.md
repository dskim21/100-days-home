# 100 Days Home

유기견 입양 후 100일 동안의 적응 과정을 행동 기반 회복 레벨로 시각화하고, 보호자에게 단계별 적응 가이드를 제공하는 웹앱입니다.

## 프로젝트 소개

`100 Days Home`은 단순한 반려견 기록 앱이 아닙니다.

유기견 입양 초기 보호자가 느끼는 불안과 궁금증을 줄이기 위해, 매일의 간단한 체크인을 기반으로 강아지의 적응 상태를 회복 레벨, 타임라인, 업적 형태로 보여주는 서비스입니다.

## 문제 정의

유기견 입양 초기에는 보호자가 이런 고민을 자주 하게 됩니다.

- 우리 강아지가 잘 적응하고 있는 걸까?
- 아직 경계하거나 숨어 있는 게 괜찮은 걸까?
- 오늘 처음 꼬리를 흔든 게 의미 있는 변화일까?
- 산책을 무서워하는데 어떻게 도와줘야 할까?

기존 반려동물 앱은 주로 사진 기록, 건강 기록, 산책 기록에 집중되어 있습니다.  
하지만 입양 후 심리적 적응 과정을 도와주는 서비스는 부족합니다.

## 핵심 기능

- 반려견 프로필 등록
- 하루 체크인
- 행동 기반 회복 점수 계산
- 회복 레벨 시스템
- Rule 기반 오늘의 적응 코치
- 100일 적응 타임라인
- 첫 순간 업적 시스템
- LocalStorage 기반 데이터 저장

## 회복 레벨

- Lv1 적응 준비
- Lv2 환경 탐색
- Lv3 신뢰 형성
- Lv4 안정화
- Lv5 가족 완성

## MVP 범위

이번 MVP에서는 로그인, 서버 DB, 실제 AI API를 제외하고  
프론트엔드 중심으로 핵심 사용자 경험을 구현했습니다.

포함:
- 프로필 등록
- 체크인 저장
- 회복 레벨 계산
- 적응 코치 메시지
- 타임라인
- 업적 unlock

제외:
- 로그인
- 사진 업로드
- 다중 반려견 관리
- 커뮤니티
- 실제 AI API
- 서버 DB

## 프로젝트 의도

이 프로젝트는 실제 유기견 입양 경험에서 출발했습니다.

입양 초기 보호자가 느끼는 막연한 불안을 줄이고,  
작은 행동 변화를 회복의 과정으로 인식할 수 있도록 돕는 것이 목표입니다.
