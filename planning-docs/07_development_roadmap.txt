=========================================
07. DEVELOPMENT ROADMAP
100 Days Home
=========================================

[목표]
1~2주 안에 포트폴리오용 MVP 완성

-----------------------------------------
DAY 1. 프로젝트 세팅
-----------------------------------------
- Vite + React + TypeScript 생성
- Tailwind CSS 설정
- React Router 설정
- Zustand 설치
- 기본 폴더 구조 생성
- 기본 레이아웃 작성

완료 기준:
- Home, Check-in, Timeline, Achievement, My Dog 페이지 이동 가능

-----------------------------------------
DAY 2. 타입/상수/스토어 설계
-----------------------------------------
- DogProfile 타입 작성
- CheckIn 타입 작성
- Emotion 타입 작성
- BehaviorTag 타입 작성
- Achievement 타입 작성
- behaviorTags constants 작성
- emotions constants 작성
- levels constants 작성
- achievements constants 작성
- useDogStore 생성
- LocalStorage persist 설정

완료 기준:
- 프로필과 체크인 데이터를 store에 저장 가능

-----------------------------------------
DAY 3. 프로필 등록 기능
-----------------------------------------
- MyDogPage 구현
- 프로필 입력 폼
- 프로필 수정 기능
- 입양일 기반 Day 계산
- 프로필 없을 때 홈에서 등록 유도

완료 기준:
- 강아지 이름과 입양일 저장 가능
- 홈에서 Day N 표시 가능

-----------------------------------------
DAY 4. 체크인 기능
-----------------------------------------
- CheckInPage 구현
- 감정 선택 UI
- 행동 태그 선택 UI
- 한 줄 메모 입력
- 체크인 저장
- 저장 후 홈으로 이동

완료 기준:
- 하루 체크인 데이터가 store에 쌓임

-----------------------------------------
DAY 5. 회복 레벨 계산
-----------------------------------------
- calculateCheckInScore 함수 구현
- calculateTotalScore 함수 구현
- getCurrentLevel 함수 구현
- 레벨 카드 UI 구현
- 진행률 바 구현

완료 기준:
- 체크인에 따라 회복 레벨이 변함

-----------------------------------------
DAY 6. 적응 코치 메시지
-----------------------------------------
- generateCoachMessage 함수 구현
- Rule 기반 메시지 작성
- 홈에 오늘의 코치 카드 표시
- 체크인이 없을 때 기본 안내 문구 표시

완료 기준:
- 최근 체크인 상태에 따라 다른 코칭 메시지가 표시됨

-----------------------------------------
DAY 7. 타임라인 구현
-----------------------------------------
- TimelinePage 구현
- 체크인 날짜순 정렬
- Day N 표시
- 감정/행동/메모 표시
- 빈 상태 UI 작성

완료 기준:
- 체크인 기록을 시간순으로 볼 수 있음

-----------------------------------------
DAY 8. 업적 시스템 구현
-----------------------------------------
- achievement constants 작성
- unlockAchievement 로직 구현
- AchievementPage 구현
- 잠금/해제 상태 UI 구분
- 체크인 저장 시 첫 행동 여부 확인

완료 기준:
- 특정 행동 첫 기록 시 업적이 해제됨

-----------------------------------------
DAY 9. 홈 대시보드 완성
-----------------------------------------
- 프로필 요약
- 현재 레벨
- 100일 진행률
- 오늘 체크인 버튼
- 오늘의 코치
- 최근 타임라인 3개
- 최근 업적 표시

완료 기준:
- 앱의 핵심 가치가 홈에서 바로 보임

-----------------------------------------
DAY 10. UI 다듬기
-----------------------------------------
- 모바일 반응형 정리
- 카드 스타일 통일
- 버튼 스타일 통일
- 빈 상태 문구 개선
- 감성 문구 추가
- 아이콘 추가

완료 기준:
- 포트폴리오 캡처 가능한 화면 퀄리티

-----------------------------------------
DAY 11. README 정리
-----------------------------------------
- 프로젝트 소개
- 문제 정의
- 핵심 기능
- 기술 스택
- 실행 방법
- 회고 작성
- 스크린샷 추가

완료 기준:
- GitHub 업로드 가능

-----------------------------------------
DAY 12. 배포
-----------------------------------------
- Vercel 배포
- 배포 오류 수정
- 모바일 화면 확인
- README에 Live Demo 링크 추가

완료 기준:
- 외부에서 접속 가능한 Live Demo 완성
