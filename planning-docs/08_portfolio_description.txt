=========================================
08. PORTFOLIO DESCRIPTION
100 Days Home
=========================================

[포트폴리오용 프로젝트 설명]

100 Days Home은 유기견 입양 후 100일 동안의 적응 과정을 돕는 웹앱입니다.

입양 초기 보호자는 강아지의 작은 행동 변화에도
"잘 적응하고 있는 걸까?"라는 불안을 느끼기 쉽습니다.

이 프로젝트는 그런 불안을 줄이기 위해,
하루 체크인 데이터를 바탕으로 강아지의 회복 단계를 시각화하고
보호자에게 적응 가이드를 제공하도록 설계했습니다.

[기획 의도]

실제 유기견 입양 경험에서 출발한 프로젝트입니다.

단순히 사진이나 일상을 기록하는 앱이 아니라,
입양 후 적응 과정을 보호자가 이해하고 안심할 수 있도록 돕는 서비스가 필요하다고 생각했습니다.

그래서 "기록"보다 "회복 여정"에 초점을 맞췄습니다.

[핵심 기능]

1. 반려견 프로필 등록
입양일을 기준으로 Day N을 계산하고, 100일 여정의 기준을 만든다.

2. 하루 체크인
감정 상태와 행동 태그를 선택해 짧고 부담 없이 기록한다.

3. 회복 레벨 시스템
행동 태그를 점수화하여 현재 적응 단계를 Lv1~Lv5로 보여준다.

4. 오늘의 적응 코치
AI API 없이 Rule 기반으로 보호자에게 상황별 안내 메시지를 제공한다.

5. 타임라인
작은 변화들을 시간순으로 쌓아 보호자가 회복 과정을 확인할 수 있게 한다.

6. 첫 순간 업적
첫 꼬리 흔들기, 첫 이름 반응, 첫 산책 성공 같은 행동을 업적으로 저장한다.

[기술적 포인트]

- React + TypeScript 기반 SPA 구현
- Zustand를 활용한 전역 상태 관리
- LocalStorage persist를 통한 데이터 유지
- 행동 태그 기반 점수 계산 로직 구현
- Rule 기반 메시지 추천 로직 구현
- React Router를 활용한 페이지 분리
- Tailwind CSS 기반 반응형 UI 구성

[문제 해결 포인트]

일반적인 기록 앱은 사용자가 직접 기록을 해석해야 한다.

100 Days Home은 체크인 데이터를 바탕으로
현재 회복 레벨과 코칭 메시지를 제공해
사용자가 변화를 더 쉽게 이해할 수 있도록 했다.

[사용자 경험 포인트]

- 긴 기록이 필요 없는 3초 체크인
- 회복 레벨로 현재 상태를 직관적으로 파악
- 첫 순간 업적으로 작은 변화도 의미 있게 저장
- 100일 진행률로 여정의 감각 제공
- 보호자를 안심시키는 문장 톤

[면접 설명 예시]

"100 Days Home은 제가 유기견을 입양하며 느낀 문제에서 출발한 프로젝트입니다.
입양 초기에는 강아지가 잘 적응하고 있는지 판단하기 어려운데,
기존 반려동물 앱은 사진이나 건강 기록 중심이라 심리적 적응 과정을 도와주지는 못한다고 느꼈습니다.
그래서 보호자가 매일 간단히 체크인하면 행동 데이터를 기반으로 회복 레벨과 코칭 메시지를 보여주는 웹앱을 기획하고 구현했습니다.
기술적으로는 Zustand와 LocalStorage를 활용해 서버 없이도 MVP를 완성했고,
행동 태그 기반 점수 계산 로직과 Rule 기반 메시지 추천 로직을 직접 설계했습니다."

[트러블슈팅 예상 항목]

1. 레벨 계산 기준이 너무 단순한 문제
- MVP에서는 누적 점수 기반으로 시작
- 추후 최근 7일 가중치 또는 부정 행동 감쇠 로직으로 개선 가능

2. AI 없이 코칭이 단조로울 수 있는 문제
- Rule 기반 조건을 여러 개로 나누고, 상황별 메시지를 다양화
- 추후 AI API 연동으로 확장 가능

3. 데이터가 LocalStorage에만 저장되는 문제
- MVP에서는 빠른 완성을 위해 LocalStorage 사용
- 추후 Supabase 연동으로 사용자별 데이터 관리 가능

[확장 계획]

- Supabase 기반 로그인/DB
- 사진 아카이브
- AI 적응 코치
- 주간 회복 리포트
- 100일 회고 카드 생성
- 다중 반려견 지원
